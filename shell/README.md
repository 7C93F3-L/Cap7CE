# Cap7CE WinUI 开发壳

C# / WinUI 3、.NET 10、x64 的阶段 F 独立开发入口。按当前主线实际使用的界面迁入整体布局，采用原生控件；Electron 继续保留。排除未使用代码、退役页面和待机线，不复制整套 React/CSS。

```powershell
pwsh -File shell/build.ps1
pwsh -File shell/run.ps1
# 可选择一个已经存在的 Catalog
pwsh -File shell/run.ps1 -Catalog <existing-catalog.db>
```

输出位于 `shell/artifacts/winui`。旧的材质演示参数已移除；在设置→外观中切换 Mica / Mica Alt，菜单与临时浮层统一使用亚克力。构建需要 Windows x64、.NET 10 SDK、现有 Core 原生构建所需的 x64 C++ 工具；缺少的固定 Core 资源按需生成。非打包运行，携带固定 Windows App SDK 1.8 运行时，.NET 使用本机 Runtime，不生成安装包。

## 本轮已接线

- 左栏此电脑、收藏列表、添加/移除收藏、显示名称及顺序调整。
- 顶部筛选栏采用80 DIP紧凑分组内容及原生横向滚动；日历时间预设、自定义日期、12类图标与组合扩展名、大小预设/范围，按类型显示颜色/明暗/饱和度、常用和自定义比例、尺寸/动静/时长/声道/字体/数量条件。图像支持精确或范围尺寸，视频分辨率和声道可多选，音视频各用主线自己的时长预设。各组编辑与清除保留其余条件；独立纯条件检查：`dotnet run --project shell/Cap7CE.Filter.Tests -c Release`。
- 共用路径/搜索区、可点击面包屑、上级/刷新、随机开关与换批、直接排序/隐藏/子目录控制及尺寸浮层；窄窗口保留更多操作菜单。单页隐藏标签行，Ctrl+T打开多页后沿原TabView与各自历史导航。
- 此电脑首页以系统目录/磁盘分组，复用现用目录图标。方形GridView、原比例ItemsRepeater均使用原生虚拟化；原比例满行排齐、末行自然宽度，比例只来自已请求缩略图，未知时暂按1。不提取属性或预扫描图片。保留低高度横向模式、原列表和100项增量分页，卡片卸载/隐藏释放像素，限制两个已接纳视觉任务。原比例支持Ctrl/Shift选择、方向键导航、右键/拖出，空白和Escape清选；交互与视觉待用户统一验收。
- 右侧选择信息、手动关键词读取与带修订冲突检查的保存、可调宽度。
- 统一文件动作：预览、默认程序打开、资源管理器定位、复制文件/路径、最多200项拖出、确认后移到回收站。只通过原 Core 可回收删除，不回退永久删除。删除前关闭预览、释放读取；本次成功删除项在当前壳会话内过滤，避免旧目录记录再次出现。
- 独立预览窗口：Core 图片、正文、PDF翻页、Office转换、电子书正文、压缩包目录和字体元信息；音视频使用原生媒体控件。目录及无内容预览格式显示基本信息。支持前后文件及默认程序打开。
- 设置：搜索、常规、外观、独立视觉缓存统计/清理、目录状态、窗口快捷键说明、现有运行组件/模型选择及手动加载/卸载、诊断导出、关于。

专用筛选已接入文档页数/图文、PSD/AI/CDR画板、三维类型/结构/面数、模型参数/精度、字体、文本/CSV/JSON及压缩包条件，预设直接来自主线转换器。三维类型只约束扩展名，不依赖元数据。属性与颜色按当前目录和类型分别执行有界只读检查，旧检查取消并忽略迟到结果；缺失或失败时提示重新检查，无轮询。原生属性提取控制尚未迁入，需先在Electron主线手动准备属性后重查，不自动扫描或建库。以上表示代码已接线，本轮按要求未进行交互验收，各格式和目标软件接收拖出仍需实际验证。

后续启动检查已修复筛选栏首次布局退出，确认主窗口存活并响应；未展开交互回归。启动/未处理异常写入独立PhaseF目录的 `last-startup-error.log`，仅保留最近一次失败，不上传。

## 数据与模块边界

`CoreConnection` 复用现有 SC/1 协议、同用户命名管道、PID/密钥认证、签名游标和取消。UI只引用 Protocol；`Cap7CE.QueryHost` 引用现有 Host/Catalog，连接已有库，不初始化数据库、不启动 Reader、不恢复建库/属性调度。默认会话仅开放状态、目录解析、搜索分页/取消；WinUI交互会话额外开放关键词读写，写入只由保存按钮触发。缺库或不可查询目录明确失败，不自动重建或回退全盘枚举。

收藏和模型显式选择复用原 Core 配置域与现有文件；首次读取不迁移资料。WinUI布局/外观写入独立的 `Cap7CE-PhaseF/shell-preferences.json`，图片视觉缓存也在该独立根；不清理 Electron 缓存。Office/Provider继续使用各自 Core 的临时资源所有权。

`Themes` 集中颜色、材质、样式；`Models` 管理视图模型与条件；`Controllers` 管理查询代次/分页/历史；`Services` 管理宿主、偏好与文件动作；`Controls/Views` 管理实际界面。MainWindow只组合这些模块。SVG以Content链接复用当前格式注册表和目录/磁盘/品牌图标，格式与提取器版本由原定义生成，不另写一份注册表。

## 暂缺与明确排除

停靠/micro/mini、托盘、全局快捷键录制、窗口/标签会话恢复、自动更新、通知、目录监听/建库及属性任务控制、AI关键词批处理尚未迁入。待机线按用户要求完全排除。外部文件变更依赖已有Catalog更新和手动刷新；此壳不接管Reader维护。

高级属性面板先提供基础条件，尚未完整迁入颜色、复合范围、声道/编码、画板与结构等全部控件。字体动态字样、交互式三维、PSD画板、完整预览侧栏、图片缩放/动画等专用查看器尚不具备完整对等能力。物理改名、剪切/粘贴及文件移动未暴露按钮。不能把这一版视为完整Electron功能验收或资源占用对比结论。

## 检查与比较

主窗口整体响应式及两侧栏宽遵循现有主线规则；两侧分隔条可拖动、用左右方向键微调或双击恢复默认宽度。自动压缩不覆盖手动选择的栏宽，低高度隐藏左栏后仍可从工具栏菜单打开面板或设置。纯布局验证：`dotnet run --project shell/Cap7CE.Layout.Tests/Cap7CE.Layout.Tests.csproj -c Release`。

```powershell
node scripts/winui-shell-boundary-check.cjs
git diff --check
# 独立临时库烟测，按需单独执行
dotnet run --project shell/Cap7CE.Smoke/Cap7CE.Smoke.csproj -c Release -- .
```

烟测使用临时合成记录和PNG，验证真实跨进程查询/分页、默认会话写入口拒绝及视觉；它不覆盖本轮所有新增UI。当前迁移轮仅集中编译、源边界与差异检查，不做长时间测试或交互验证。

显式调用 `shell/measure.ps1 -ProcessId <root-pid> -Label <label>` 可有限采样壳及子进程树的工作集、私有内存、CPU与进程数。比较需相同功能、数据、窗口、滚动和冷热缓存条件；工作集之和包含共享页。实际路径、机器信息和测量结果保存在公开仓库之外。
