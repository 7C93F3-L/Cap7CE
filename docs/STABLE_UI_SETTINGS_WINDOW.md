# Cap7CE 稳定 UI 独立 Settings

> 轮次：U6 宿主 + U7 正式内容
>
> 状态：U7 自动验证与人工确认通过
>
> U6–U7 当时仅通过开发入口验收；D0 后由正式 `stable` 模式使用同一独立 Settings，见 `docs/STABLE_UI_DEFAULT_HOST.md`

## 1. 宿主与回退边界

稳定 UI 的 Settings 按钮、全局快捷动作、托盘菜单、通知点击和 Preview 入口统一调用同一个打开动作。正式 `stable` 模式下，该动作只创建或恢复独立 Settings `BrowserWindow`；旧 cap7ce / compatibility 外壳继续进入主窗口内的原 Settings 页面。关闭按钮只隐藏 Settings 自身，主窗口、Preview、搜索、Skim、选择和滚动状态保持不变。

`SettingsWindowController` 独占窗口创建、加载、显示、聚焦、隐藏和退出销毁生命周期。Settings 继续使用独立版本 1 布局文件，默认尺寸 `860 × 680`、最小尺寸 `620 × 480`；记录不会写入 normal 布局，也不会触发 micro / mini / normal 自动形态切换。

## 2. U7 内容与状态边界

独立 Renderer 按通用、外观、浏览与 Skim、搜索与 AI、缓存与索引、快捷键、诊断、关于八类组合正式内容，并提供当前语言下的本地条目筛选。新版较详细的分类和说明作为当前文案方向；旧版存在而新版原型未逐项对应的正式能力补入合适分类。未冻结的新旧增删改和遗漏项允许在后续使用中继续调整，不要求 U7 一次性锁定最终文案清单。

页面直接调用现有偏好、缓存、嵌入元数据、快捷键、诊断、llama.cpp、模型和应用更新 IPC，并复用既有复杂设置行。嵌入元数据在 stable Settings 中只复用任务状态和动作，不再渲染旧设置页的重复标题及内层设置行；快捷动作与快捷指令列表在新版中常驻显示，启用与恢复默认等操作进入标题行，不再保留旧版收起 / 展开容器、重复标题或配置完成按钮。快捷指令正文作为只读命令说明表，在宽窗口中分两列、窄窗口中切为一列，展开前后宽度变化和折叠动效不再参与新版布局。“诊断”仅承载 Cap7CE 日志、崩溃报告、详细记录和诊断包操作；llama.cpp 的文件、服务、目录与模型状态移入“搜索与 AI”并紧跟对应设置。旧 Settings 保持原布局。目录配置已由新版主界面的目录列表完整承担，独立 Settings 不再重复提供添加、重命名或删除入口；底层目录广播仍保持，以免形成第二套状态链。`useSettingsWindowController` 只组合显示状态，不建立第二份 Store 或后台任务。

新版 Settings 将该分类直接命名为“自定义查看”，说明文案作为页面副标题，格式配置常驻展开并使用响应式双列分类卡片；文件格式按钮独立使用 24px 紧凑高度与最大胶囊圆角，不受普通操作按钮的 28px 最小高度约束，隐藏文件与格式分类通过开关操作，已选格式保持主题渐变，未选格式保持透明并在悬停时显示普通圆角背景。旧版 Settings 继续保留原折叠行。line 归入“通用”的窗口设置。两类缓存清理和快捷键占用仍沿用原确认、授权与回滚语义；更新下载、运行时启停、模型选择和诊断导出仍由既有服务执行。

## 3. 当前视觉与窗口材质边界

U7 先完成正式内容和响应式布局，不把细节样式当作最终 U11 收口结果。U10 已把稳定 UI 的独立 Settings 与主窗口、Preview 统一为 `frame: true`、40 DIP WCO 和 Acrylic；系统拒绝 Acrylic 时回退当前主题安全纯色。D0 将其作为正式 stable 宿主，旧 compatibility 仍保持 36 DIP 与 Mica。

普通设置按小标题整组合并到一块 22px 圆角背景中，组内设置行保持透明并以轻分隔线区分，不再让不同长度和内容类型的条目各自形成长胶囊。滚动区内只建立一条最大 1000px、随可用空间收缩的内容轨道，所有页面标题、小标题、普通分组和“自定义查看”外框必须占满该轨道；轨道在宽窗口中于导航栏右侧的完整可见内容区域内居中，空间不足时自动铺满，分类自身不再持有独立最大宽度。独立 Settings 不具备主界面 `.app` 外壳，故共享自绘滚动框自身提供 8px 热区和 4px 滑块默认值，Settings 同时补齐随明暗主题变化的滑块颜色，并将滚动条贴附于内容表面右缘而不为其保留独立网格列，确保显式内容网格有效且卡片左右留白一致。滚动条继续仅在内容溢出时建立，滚动或指向热区后显示并在空闲时自动隐藏。分类栏使用同一套 24px 坐标系、统一描边及圆角端点的语义 SVG；正常宽度显示 16px 图标加文字，700px 以下仅保留 17px 居中图标，不再使用字符占位。侧栏搜索框使用最大胶囊圆角并取消容器焦点描边；中文输入法组合期间只更新输入内容，候选词确认后才执行页面筛选，英文和已确认文本仍实时响应。“自定义查看”的格式分类卡片仅在统一内容轨道内部维持自身响应式布局。普通操作按钮统一使用 28px 高度、最大胶囊圆角、半透明底色和颜色1至颜色2的渐变悬停 / 键盘焦点反馈；开关、下拉框、字体滑块、格式选择和左侧导航保持各自控件语义。独立 Settings 的语言、窗口材质、主题、运行时与模型选择复用 Renderer 自绘下拉组件，浮层使用主界面菜单的半透明圆角与主题渐变反馈，并保留键盘导航、视口避让和外部关闭能力；llama.cpp 与模型选择框固定使用同一加宽尺寸及控制区起点，窄窗时再按可用宽度收缩。

700px 以下的普通设置卡片统一将标题与说明置于上方、控件置于下一行：单控件和颜色等多控件组从左侧起排，状态加操作的组合仍保持状态靠左、按钮靠右。运行时与模型下拉框改为弹性占用操作按钮之外的剩余宽度，两行按钮列保持一致；诊断信息继续使用标签、值和紧凑操作三列，不把操作按钮拉伸为整行。快捷动作、快捷指令和自定义查看仍按各自内容结构使用已有窄窗布局。

“配置外观”的主题色与副色入口复用旧版完整自绘拾色器，不再调用系统原生颜色面板；两个胶囊入口显示当前颜色，同行最右侧提供恢复默认操作，色板外框与主界面浮层一致。明度 / 饱和度、色相和 HEX 修改会即时预览，点击外部提交，按 `Esc` 取消并恢复打开前的颜色。

“窗口材质”提供“亚克力 / 云母”两项持久化选择，并通过正式偏好 IPC 实时同步主窗口、独立 Settings 与 Preview，无需重启窗口。系统或 Electron 拒绝所选材质时自动回退当前主题的安全纯色；纯色只承担兼容回退，不作为第三个主动选项。旧 Cap7CE / compatibility 宿主保持自身材质策略。

“字体大小”位于外观分类末尾，以五档滑块提供持久化选择，按照真实顺序显示“小 / 标准 / 空 / 空 / 大”，不展示具体字号。拖动过程只更新滑块草稿值，松开指针、完成键盘调整或离开控件后才一次性提交，避免 Settings 自身连续改变字号和行高造成重排抖动。提交后同步 stable 主窗口、独立 Settings、稳定 Preview、Portal 标题栏和共享浮层；旧 Cap7CE / compatibility 宿主及 Markdown、代码、电子书、字体样张等文件内容维持自身排版。

## 4. U7 人工验收清单

1. 运行 `npm run dev:stable-ui`，打开 Settings，确认左侧八个分类、搜索框和各分类正式内容均可见；缩放窗口时内容连续重排，没有固定尺寸强制回弹。
2. 搜索一个设置标题或说明中的中英文词，确认只显示匹配分类 / 条目；清空后恢复当前分类。
3. 修改语言、主题、通知、提示、AI、line 等安全偏好，确认主窗口无需重启即可同步；从旧入口修改后重新查看独立 Settings，也应同步。
4. 检查“浏览与 Skim”不再出现目录管理，自定义查看无需展开即可直接配置；确认隐藏文件、恢复默认、类别和单项格式按钮均可用。
5. 检查 line 已进入“通用”，并继续检查运行时 / 模型、缓存统计与清理、快捷键捕获、诊断和版本更新；确认操作沿用现有任务状态、禁用条件和错误反馈。
6. 切换“窗口材质”的亚克力 / 云母选项，确认主窗口、Settings 与已打开 Preview 实时同步；不支持所选材质时应回退安全纯色。切换窗口呈现模式仍属于既有受控重启功能。
7. 依次切换“字体大小”的 12px 与 16px 档，确认主窗口、Settings、已打开 Preview、标题栏和浮层立即同步；检查最窄窗口、长文案和中文输入框无裁切，文件内容预览字号保持不变。
8. 逐项打开语言、窗口材质、主题、运行时和模型下拉框，确认浮层可避让窗口边缘并支持鼠标与键盘选择；打开两种颜色的拾色器，确认实时预览、外部保存和 `Esc` 取消均正确。
9. 点击原生关闭按钮后再次打开 Settings，确认窗口只隐藏并恢复同一实例，位置和尺寸记忆仍有效；主窗口与 Preview 不受影响。
10. 运行普通旧界面，确认旧 Settings 仍可用，不会同时打开独立窗口。
