# Cap7CE 稳定 UI 独立 Settings

> 轮次：U6 宿主 + U7 正式内容
>
> 状态：U7 自动验证与人工确认通过
>
> U6–U7 当时仅通过开发入口验收；D0 后由正式 `stable` 模式使用同一独立 Settings，见 `docs/STABLE_UI_DEFAULT_HOST.md`

## 1. 宿主与回退边界

稳定 UI 的 Settings 按钮、全局快捷动作、托盘菜单、通知点击和 Preview 入口统一调用同一个打开动作。正式 `stable` 模式下，该动作只创建或恢复独立 Settings `BrowserWindow`；旧 cap7ce / compatibility 外壳继续进入主窗口内的原 Settings 页面。关闭按钮只隐藏 Settings 自身，主窗口、Preview、搜索、Skim、选择和滚动状态保持不变。

`SettingsWindowController` 独占窗口创建、加载、显示、聚焦、隐藏和退出销毁生命周期。Settings 继续使用独立版本 1 布局文件，默认尺寸 `860 × 680`、最小尺寸 `620 × 480`；记录不会写入 normal 布局，也不会触发 micro / mini / normal 自动形态切换。

## 2. U7 内容与状态边界

独立 Renderer 按通用、外观、浏览与 Skim、搜索与 AI、缓存与索引、快捷键、诊断、关于八类组合正式内容，并提供当前语言下的本地条目筛选。新版较详细的分类和说明作为当前文案方向；旧版存在而新版原型未逐项对应的正式能力补入合适分类。未冻结的新旧增删改和遗漏项允许在后续使用中继续调整，不要求 U7 一次性锁定最终文案清单。

页面直接调用现有偏好、缓存、嵌入元数据、快捷键、诊断、llama.cpp、模型和应用更新 IPC，并复用既有复杂设置行。目录配置已由新版主界面的目录列表完整承担，独立 Settings 不再重复提供添加、重命名或删除入口；底层目录广播仍保持，以免形成第二套状态链。`useSettingsWindowController` 只组合显示状态，不建立第二份 Store 或后台任务。

新版 Settings 将该分类直接命名为“自定义查看”，说明文案作为页面副标题，格式配置常驻展开并使用响应式双列分类卡片；隐藏文件与格式分类通过开关操作，已选格式保持主题渐变，未选格式保持透明并在悬停时显示普通圆角背景。旧版 Settings 继续保留原折叠行。line 归入“通用”的窗口设置。两类缓存清理和快捷键占用仍沿用原确认、授权与回滚语义；更新下载、运行时启停、模型选择和诊断导出仍由既有服务执行。

## 3. 当前视觉与窗口材质边界

U7 先完成正式内容和响应式布局，不把细节样式当作最终 U11 收口结果。U10 已把稳定 UI 的独立 Settings 与主窗口、Preview 统一为 `frame: true`、40 DIP WCO 和 Acrylic；系统拒绝 Acrylic 时回退当前主题安全纯色。D0 将其作为正式 stable 宿主，旧 compatibility 仍保持 36 DIP 与 Mica。

“窗口材质”仍显示 `Acrylic（目标，只读）`，因为用户选择材料的设置功能尚未接入；正式 stable 宿主已真实使用 Acrylic / 安全纯色回退，但不提供无效选择。材质选择功能与进一步视觉调整留给后续独立轮次。

## 4. U7 人工验收清单

1. 运行 `npm run dev:stable-ui`，打开 Settings，确认左侧八个分类、搜索框和各分类正式内容均可见；缩放窗口时内容连续重排，没有固定尺寸强制回弹。
2. 搜索一个设置标题或说明中的中英文词，确认只显示匹配分类 / 条目；清空后恢复当前分类。
3. 修改语言、主题、通知、提示、AI、line 等安全偏好，确认主窗口无需重启即可同步；从旧入口修改后重新查看独立 Settings，也应同步。
4. 检查“浏览与 Skim”不再出现目录管理，自定义查看无需展开即可直接配置；确认隐藏文件、恢复默认、类别和单项格式按钮均可用。
5. 检查 line 已进入“通用”，并继续检查运行时 / 模型、缓存统计与清理、快捷键捕获、诊断和版本更新；确认操作沿用现有任务状态、禁用条件和错误反馈。
6. 确认“窗口材质”仍只显示 Acrylic 目标只读状态；stable 宿主实际使用 Acrylic，系统不支持时为安全纯色，但当前仍不可手动选择材料。切换窗口呈现模式仍属于既有受控重启功能。
7. 点击原生关闭按钮后再次打开 Settings，确认窗口只隐藏并恢复同一实例，位置和尺寸记忆仍有效；主窗口与 Preview 不受影响。
8. 运行普通旧界面，确认旧 Settings 仍可用，不会同时打开独立窗口。
