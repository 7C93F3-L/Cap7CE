# Cap7CE 稳定 UI 响应式空壳

> 轮次：U2
> 状态：人工确认通过
> U2 当时仅通过开发入口验收；D0 后由正式 `stable` 模式使用同一响应式壳层，见 `docs/STABLE_UI_DEFAULT_HOST.md`

## 1. 本轮边界

U2 只建立顶部标题栏、左侧栏、中央结果占位区和右侧 Skim 占位区。占位块不读取用户目录、文件、搜索词或 Skim 内容；除显示 / 隐藏 Skim 和调整两处分隔线外，没有接入业务操作。搜索、目录与 Skim 功能从后续轮次按 U0 迁移映射逐项接入。

新版窗口继续采用单一连续响应式布局。micro、mini、normal 只保留为旧界面兼容名称，不参与新版内容切换；stable 不再提供横向或纵向尺寸预设，用户自由拖动与缩放不会触发形态转换或强制回弹。Windows 原生最大化、还原、Snap、系统菜单和窗口按钮仍由 compatibility 宿主管理。

## 2. 布局规则

- 侧栏默认 176px，与独立 Settings 导航栏保持一致，可在 40–320px 内拖动；双击分隔线恢复 176px。侧栏容器小于等于 95px 时隐藏文字，只保留紧凑图形占位。
- Skim 默认 360px，可在 280–480px 内拖动；双击分隔线恢复 360px。
- 普通高度且窗口宽度不超过 920px 时，打开 Skim 会替换中央结果区，侧栏继续保留。
- 窗口宽度不超过 560px 时，打开 Skim 会独占可用宽度，侧栏和结果区隐藏。
- 窗口高度低于 360px 时，侧栏隐藏，当前结果或 Skim 占位网格改为横向滚动；打开 Skim 时仍由 Skim 替换结果区。

这些断点只决定内容如何排列，不写窗口状态，不调用旧窗口尺寸切换动作。

窗口可以自由进入最低高度或最窄宽度布局；快捷键不保存这些临时形态。`Alt+4` 是唯一几何重置入口：先结束已有贴边收起会话，再以当前显示器工作区 82%、最大 1600×1000 的大小居中显示主窗口，不清空搜索、目录、Skim、选择或滚动状态。

左侧栏目录列表按实际内容高度增长，超出可用空间后在自身范围内滚动；列表与底部操作之间的剩余空白保留为原生窗口拖动区域。目录项、重命名输入框与自绘滚动条必须继续使用非拖动命中区，不能以扩大拖动范围为由牺牲点击、右键、编辑或滚动行为。

## 3. 组件边界

- `StableUiRoot.tsx` 只组合标题栏、置顶控制器与主空壳。
- `StableMainShell.tsx` 只组合布局；`useStableShellLayout.ts` 持有 Skim 显隐状态，`useStableShellResize.ts` 持有两侧宽度及指针 / 键盘调整。
- `StableShellSidebar.tsx`、`StableSkimSlot.tsx` 与 `StablePlaceholderGrid.tsx` 只展示人工占位内容。
- `StableMainShell.css` 持有 U2 布局和断点，`StableShellResize.css` 持有分隔线；`StableUiFoundation.css` 继续只持有 U1 共用变量、标题栏和滚动条基础。

## 4. 人工验收清单

1. 连续拖动窗口宽度和高度，确认内容平滑重排，窗口不会自动回弹或切换旧形态。
2. 拖动侧栏和 Skim 分隔线，确认范围受限；双击分隔线确认恢复默认宽度。
3. 在约 920px 和 560px 两侧来回缩放，确认 Skim 分别从并排变为替换结果区、再变为独占宽度；关闭 Skim 后结果区恢复。
4. 将窗口高度降到 360px 以下，确认侧栏隐藏、占位块横向排列且可以横向滚动。
5. 检查浅色 / 深色、最大化、还原、Windows Snap、标题栏拖动、系统按钮和置顶按钮。
6. 启动普通旧界面与普通 compatibility 界面，确认旧布局和窗口状态机没有变化。

U2 人工确认只判断响应式空壳是否适合继续承载功能，不确认真实搜索、目录、Skim 数据或最终尺寸快捷键。
