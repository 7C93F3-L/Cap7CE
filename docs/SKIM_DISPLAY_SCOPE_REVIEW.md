# Cap7CE Skim 显示范围审校表

> 文档状态：历史产品审校记录；已确认规则在 0.8.1 落地，后续扩展见 `REMAINING_CAPABILITY_ROADMAP.md`
> 当前行为：支持 skim、全部显示和自定义三种持久化模式
> 文档目的：确定未来“skim 模式 / 全部显示 / 自定义”的默认范围与格式分类

## 1. 建议模式

| 模式      | 建议行为                                           |
| ------- | ---------------------------------------------- |
| skim 模式 | 显示文件夹，以及下表中“skim 默认”为“显示”的文件；未知格式和无扩展名文件默认隐藏   |
| 全部显示    | 显示文件夹和全部普通文件，保持当前 Skim 行为                      |
| 自定义     | 从 skim 规则开始，允许按类别切换，并通过“始终显示 / 始终隐藏”的扩展名覆盖默认规则 |

建议覆盖优先级：

```text
始终隐藏扩展名
  > 始终显示扩展名
  > 自定义类别开关
  > skim 模式默认值
```

“已经登记”只说明 Cap7CE 知道该格式的类别、图标或预览能力，不代表它必须在 skim 模式中显示。“显示”也不等于“已经支持内容预览”；尚未接通解析器的格式继续使用文件信息预览。

## 4. 已确认规则

1. 模式名称使用“skim 模式 / 全部显示 / 自定义”。
2. `.html` 不进入 skim 默认范围。
3. `.json`、`.xml`、`.yaml`、`.yml` 归入默认隐藏的“配置与数据”。
4. `.woff`、`.woff2` 归入默认隐藏的“网页与开发文件”。
5. `.obj` 继续按 3D 文件默认显示，接受少量编译产物混入。
6. `.bip` 是 KeyShot 场景，`.ksp` 是 KeyShot 打包工程，两者显示。
7. `.bld` 和 `.pr` 是错误缩写登记，分别由 `.blend` 和 `.prproj` 替换；图标同步改名为 `format-blend` 和 `format-prproj`。
8. 带 Windows 隐藏属性的普通文件在 skim 模式隐藏，在全部模式显示。
9. `.rtf`、`.csv`、`.gz`、`.tar` 按用户表格标注改为 skim 默认隐藏。

## 5. 第二轮待审校项目

2. 第 2.10 节四类待补充格式是否需要删减、改为默认隐藏或补充其他扩展名。
3. 第 2.11 节专业影像源文件是否全部进入 skim 默认范围。
4. 自定义模式是否也默认隐藏 Windows 隐藏属性文件，还是允许单独开启。

完成第二轮审校后，再决定设置页布局、偏好数据结构、图标资产和当前目录临时筛选方式；本文件本身不授权修改现有 Skim 行为。
