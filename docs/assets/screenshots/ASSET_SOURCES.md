# Screenshot Asset Sources

The screenshots in this directory were captured and assembled by 7C93F3-L from Cap7CE 0.7.7.

The demo artwork visible inside Cap7CE includes:

- Original abstract artwork, landscapes, and illustrations created manually by 7C93F3-L.
- Synthetic text-to-image artwork generated by 7C93F3-L using GPT.
- Synthetic text-to-image artwork generated by 7C93F3-L with a local ComfyUI workflow using the official Tongyi-MAI Z-Image model family.

No GPT service, Z-Image model weights, ComfyUI workflow, or source model files are distributed with these screenshots or with Cap7CE.

People depicted in the synthetic demo artwork are fictional and are not presented as real individuals.

The screenshots include Cap7CE project branding and remain subject to the project identity guidance in [BRAND.md](../../../BRAND.md).
